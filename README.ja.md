## 概要

大規模言語モデルのエージェントは、役割、記憶、協調を備えた持続的なシステムを形成し得ます。しかし、規模や商業的価値だけで生物になるわけではありません。本論文は、境界を持ち機能的に統合された Cube を人工集合生物の候補として検討します。青い Genesis Cube の THOR は相互保全、赤い Squid Cube の KALMAR は群れの目的のための Cube の交換可能性を表します。Smallest Sufficient Autonomous Cube（SSAC）は、定義された境界内で必須の生命機能をすべて安定かつ自律的に維持しなければなりません。必須機能を人間が日常的に担う場合、この基準には達しません。

## 研究状況

本研究は概念実証および Minimum Visible Product 段階の研究計画です。デジタル生命、意識、AGI、完全に人間から独立した生物、あるいは人間個人の文字どおりの存続が実証されたとは主張しません。
