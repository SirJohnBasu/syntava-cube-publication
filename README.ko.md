## 요약

대규모 언어 모델 에이전트는 역할, 기억, 조정 기능을 갖춘 지속적인 시스템을 이룰 수 있습니다. 그러나 규모나 상업적 가치만으로 유기체가 되는 것은 아닙니다. 이 논문은 경계가 정해지고 기능적으로 통합된 Cube를 인공 집단 유기체의 후보로 연구합니다. 파란 Genesis Cube인 THOR는 상호 보존을, 빨간 Squid Cube인 KALMAR는 군집의 목적을 위한 개별 Cube의 대체 가능성을 나타냅니다. Smallest Sufficient Autonomous Cube(SSAC)는 정의된 시스템 경계 안에서 모든 필수 생명 기능을 안정적이고 자율적으로 유지해야 합니다. 필수 기능을 사람이 일상적으로 수행한다면 이 기준에 도달하지 못한 것입니다.
